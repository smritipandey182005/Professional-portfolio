
# Smriti Pandey — Portfolio

A premium, dark-themed personal portfolio built with **HTML, CSS, and JavaScript**. Single self-contained file — no frameworks, no build step.

🔗 **Live demo:** _add your GitHub Pages link here_

## Features

- Animated terminal hero that "types out" a live resume summary
- Scroll-reveal animations across every section
- Interactive skill cards grouped by category (Software, Soft Skills, Core Competencies)
- Vertical timeline for professional experience
- Achievement grid covering leadership, debate wins, and awards
- Sticky, responsive navigation with a mobile menu
- Fully responsive — desktop, tablet, and mobile

## Sections

- Hero
- About
- Skills
- Experience
- Education
- Achievements (Leadership, Debate Record, Sports, Memberships)
- Resume CTA
- Contact

## Built With

- **HTML5** — semantic structure
- **CSS3** — custom properties, CSS Grid & Flexbox, animations
- **JavaScript (vanilla)** — scroll-reveal via `IntersectionObserver`, terminal typing effect, mobile menu toggle

## Getting Started

Just open `index.html` in any browser — no installation or build step required.

```bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
open index.html
```

## Customizing

- Update personal details directly in the HTML — content is organized section by section with comments.
- Colors and fonts are controlled by CSS custom properties (`:root` variables) near the top of the `<style>` block.
- Wire up the "Download Resume" / "View Resume" buttons to a hosted PDF link once available.
